# 調査・会議整理アシスタント（公開準備検証用）

公開準備を検証するための合成サンプルAgentです。調査の要点と根拠、会議の決定事項と次のアクションを整理する汎用的な手順を収録しています。

## 使い方

目的、読み手、対象資料を渡してください。選択肢を比較する場合は、比較基準や予算も指定してください。

- 調査例：「提供した資料から、選択肢を費用と導入期間で比較し、要点・根拠・次のアクションをまとめてください。」

外部情報の確認は、利用環境でアクセスできる情報源の範囲で行います。出典や担当、期日を推測で補いません。

## ファイル構成

このREADMEと同じ階層に `identity.md` を置き、Skillと共通書式は次の相対パスに配置しています。

- `identity.md`：役割と判断方針
- `.agents/skills/research-brief/SKILL.md`：調査を簡潔な提案資料にまとめる手順
- `.agents/skills/meeting-summary/SKILL.md`：会議の決定事項とアクションを整理する手順
- `knowledge/report-format.md`：共通の資料構成
- `.aachat/public.yaml`：公開名、説明、タグ
