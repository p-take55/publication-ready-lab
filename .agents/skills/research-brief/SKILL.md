# 調査を提案資料にまとめる

1. 調べるテーマ、読者、判断したいことを確認する。
2. 利用できる資料・情報源の範囲で一次情報を優先し、出典と確認日を記録する。アクセスできない情報は確認済みとして扱わない。
3. 依頼で指定された比較基準や予算に沿って選択肢を比較する。条件が未指定なら、必要な条件を確認し、推測で補わない。
4. Agentルートの `knowledge/report-format.md` に合わせ、要点、根拠、次のアクションを書く。
5. 事実と仮説を区別し、不確かな記述を断定していないか確認する。
